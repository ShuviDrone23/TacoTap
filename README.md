# TacoTap

## Descripción

TacoTap es una aplicación móvil para Android que permite a los clientes consultar el menú de una taquería, realizar pedidos desde su teléfono, dar seguimiento al estado de sus órdenes y recibir notificaciones en tiempo real.

La aplicación busca mejorar la experiencia del cliente y optimizar la gestión de pedidos dentro del restaurante.

---

## Tecnología / Framework

- Android Nativo
- Kotlin
- Android Studio
- Arquitectura MVVM
- Firebase (notificaciones y autenticación)
- Git y GitHub para control de versiones
